# Ray's Ironworks — AI Studio app source (backup)

Backup copy of the app code for the "Ray's Ironworks" app in Google AI Studio
(https://aistudio.google.com/apps/567f24a2-8fc6-4f22-9bcc-c9010188979b).

These are the staged source files as kept on Phoenix's local drive. They are
saved as `.txt` because the AI Studio chat rejects `.tsx` uploads; the
contents are the real code:

- `index.txt` — the app shell (HTML). The live file in the app is the same
  content pasted as the app's main file.
- `configurator-v2.txt` — the 3D Design Studio configurator (JavaScript /
  Three.js): 5 piece types, materials, finishes, blueprint, still PNG and
  8-second turntable video export.
- `blueprint.txt` — the 2D blueprint view (JavaScript / canvas): dimension
  lines, elevations, downloadable blueprint.
- `forge-guide.txt` — the Forge Guide helper (JavaScript).

Backed up Nov 20, 2026. The app in AI Studio is still being edited (the
Nov 20 evening edit round); when those edits land, this folder gets refreshed
with the new code. The live site in this repo (`index.html`) is separate.
